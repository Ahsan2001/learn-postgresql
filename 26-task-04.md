# Task 04

#### Create a shopping-store database structure using these four tables:

- `customers`
- `orders`
- `products`
- `order_items`

#### Requirements

1. Create a one-to-many relationship between `customers` and `orders`: one customer can have many orders, and each order belongs to one customer.
2. Create a many-to-many relationship between `orders` and `products` using the `order_items` table.
3. Give the `products` table a `price` column.
4. Add primary keys and foreign keys to connect the tables.
5. Write a query that displays one row for each product in each order, with these columns in this order: `cust_name`, `ord_id`, `ord_date`, `p_name` (product name), `quantity`, `price`, and `total_price`.
6. Calculate `total_price` for each order item by multiplying its `quantity` by the product `price`.
