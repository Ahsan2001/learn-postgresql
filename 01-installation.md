# PostgreSQL Installation

This guide explains how to install PostgreSQL on Windows and set up the database environment for learning.

## 1) Download PostgreSQL

Visit the official PostgreSQL download page:

https://www.postgresql.org/download/

Choose the Windows installer version that matches your system architecture.

## 2) Run the installer

- Download the PostgreSQL installer.
- Run the setup file.
- Select the PostgreSQL version you want to install.
- Choose the installation directory.
- Set a password for the default PostgreSQL user (for example, `postgres` or `root` if you are following a beginner setup).
- Make sure to install the included tools such as:
  - PostgreSQL Server
  - pgAdmin 4
  - Command Line Tools / SQL Shell (psql)

## 3) Complete the installation

- Finish the installation wizard.
- Wait until PostgreSQL is installed successfully.
- Start pgAdmin or SQL Shell to verify the setup.

## 4) Verify the installation

Open the SQL Shell (`psql`) and try connecting to the default PostgreSQL server.

If PostgreSQL is installed correctly, you will be able to log in and run SQL commands.

This completes the installation process.
