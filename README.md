### Learn PostgreSQL

This repository contains beginner-friendly PostgreSQL tutorials covering installation, database management, and table creation.


### Purpose

These lessons are designed to help beginners learn the core PostgreSQL operations needed to work with databases effectively.


### Getting Started

1. [Installation](./01-installation.md) - Install PostgreSQL on Windows
2. [Create a Database](./02-create-database.md) - Create a new database in PostgreSQL
3. [Change Database](./03-change-database.md) - Switch between databases
4. [Delete a Database](./04-delete-database.md) - Remove an existing database
5. [CRUD - Creating a Table](./05-crud-creating-table.md) - Create a table and view its structure
6. [CRUD - Inserting Data into a Table](./06-crud-inserting-data-in-table.md) - Insert records into a PostgreSQL table
7. [CRUD - Reading Data from a Table](./07-crud-Reading-data-in-table.md) - Read records from a PostgreSQL table
